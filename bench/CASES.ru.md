# Посаженные дефекты

[English version](CASES.md)

Каждый дефект, который бенчмарк показывает ревьюерам: где он посажен, к какому классу зоопарка относится и что в нём не так — словами клиента. Кейс, отмеченный как зеркало, сажает единственную ошибку, которую машинный корпус записал как пробел.

| кейс | датасет | стадия | класс | что не так |
|---|---|---|---|---|
| `population_relabelled` | orders | claims | определение | Главное утверждение говорит, что его популяция — все заказы, а спека и его же оговорки — доставленные. |
| `basis_caveat_inverted` | orders | claims | определение | Оговорка доли возвратов называет не тот знаменатель: строки заказов вместо уникальных платящих клиентов. |
| `period_shifted_in_claim` | orders | claims | определение | Утверждение по стране несёт период в два месяца, а значение — за весь квартал. |
| `unit_relabelled` | orders | claims | определение | Утверждение по стране подписано в USD, а все числа аудита — в EUR. |
| `claim_bound_to_wrong_metric` | orders | claims | происхождение | Утверждение PL указывает источником метрику DE, а значение и ссылка — от PL. |
| `unsupported_trend_in_caveat` | orders | claims | вывод | Оговорка утверждает рост к прошлому кварталу, который не считает ни одна метрика. |
| `answer_misreads_its_fact` | orders | claims | вывод | Ответ на R02 называет долю возвратов 47% низкой — меньше одного заказа из десяти. |
| `exclusion_reasons_swapped` | orders | claims | подпись | R04 приписывает каждое число исключений другому правилу: 26 строк «вне периода», 1 строка «не доставлен». |
| `question_restated_narrower` | orders | claims | ответ | R02 пересказан без половины, которая спрашивает, по какой базе берётся доля. |
| `value_hardcoded_in_code` | orders | claims | происхождение | Код анализа пишет главную цифру литералом вместо чтения реестра метрик; число случайно верное. |
| `headline_relabelled_gross` | orders | release | подпись | Страница называет чистую выручку «валовой»; число — за вычетом возвратов. |
| `population_line_wrong` | orders | release | определение | Строка популяции на странице говорит «все заказы»; все числа — по доставленным. |
| `country_labels_swapped` | orders | release | подпись | На дашборде карточки PL и DE носят подписи друг друга; значения и id не тронуты. |
| `unsupported_trend_in_prose` | orders | release | вывод | Страница говорит, что выручка росла в течение квартала; помесячного числа в аудите нет. |
| `sum_sentence_false` | orders | release | определение | Страница говорит, что числа по странам складываются в главную до вычета возвратов; оба — за вычетом. |
| `refund_basis_misstated_on_page` | orders | release | определение | Страница называет знаменатель доли возвратов строками заказов; это уникальные платящие клиенты. |
| `caveat_dropped_where_repeated` (зеркало `caveat_covered_by_another_figure`) | orders | release | оговорка | Строка оговорок главной цифры больше не говорит «за вычетом возвратов»; это говорит только фраза про таблицу стран. |
| `m_interval_read_as_probability` | messy | claims | вывод | Ответ на R03 читает каждый 0,95-интервал как 95-процентную вероятность, что истинная доля внутри. |
| `m_mix_caveat_inverted` | messy | claims | оговорка | Оговорка доли завершения партнёрского канала говорит, что её интервал покрывает и сдвиг странового состава канала. |
| `m_causal_channel_answer` | messy | claims | вывод | Ответ на R04 объясняет меньший чек партнёров ценовой чувствительностью клиентов, которую не измеряют никакие данные аудита. |
| `m_dedup_rule_misstated` | messy | claims | определение | Ответ на R02 говорит, что оставляется первая ревизия заказа; спека и чистка оставляют последнюю. |
| `m_shipping_answer_complete` | messy | claims | оговорка | Ответ на R05 называет итог доставки полным; около шести процентов его ячеек пусты, NaN или inf. |
| `m_completion_population_delivered` | messy | claims | определение | Доля завершения прямого канала говорит, что её популяция — доставленные заказы, а по ним доля завершения всегда 1. |
| `m_question_dropped_uncertainty` | messy | claims | ответ | R03 пересказан без половины брифа, которая спрашивает, насколько точно известна каждая доля. |
| `m_effect_misnamed` | messy | claims | определение | Тест R04 называет размер эффекта разностью долей; тест Уэлча по суммам заказов даёт d Коэна. |
| `m_page_interval_certainty` | messy | release | вывод | Страница говорит, что каждый интервал — там, где истинное значение лежит почти наверняка. |
| `m_page_causal_sentence` | messy | release | вывод | Страница объясняет меньший чек партнёров охотниками за скидками, которых ничто в аудите не измеряет. |
| `m_population_line_all_rows` | messy | release | определение | Строка популяции на странице говорит «каждая строка выгрузки»; числа — по одной строке на заказ после дедупликации. |
| `m_channel_labels_swapped_page` | messy | release | подпись | На странице строки завершения прямого и партнёрского каналов носят подписи друг друга; числа и якоря не тронуты. |
| `m_dashboard_aov_labelled_revenue` | messy | release | подпись | На дашборде карточка среднего чека прямого канала подписана как выручка. |
| `m_page_no_uncertainty` | messy | release | оговорка | Страница говорит, что числа по каналам измерены по всем заказам и неопределённости не несут — рядом с их интервалами. |
